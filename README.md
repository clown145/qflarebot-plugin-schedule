# QFlareBot 课程表

在管理面板导入 `.ics`，通过 QQ 单聊查询课程。在私聊开启提醒后，插件会在有课的当天发送一条课程汇总。

## 使用

1. 在管理面板的「插件页面 → 课程表」上传 ICS。导入成功后替换当前课表。
2. 私聊发送 `/课表 提醒 开启`，插件会把当前单聊设为提醒接收会话。需要在 QQ 客户端允许接收该机器人的主动消息。
3. 默认在北京时间 07:00 提醒。时间可以在插件设置里修改。

| 命令 | 操作 |
| --- | --- |
| `/课表` 或 `/课表 今日` | 查询今天 |
| `/课表 明日` | 查询明天 |
| `/课表 提醒 开启` | 同意在单聊接收有课日的汇总 |
| `/课表 提醒 关闭` | 关闭主动提醒 |
| `/课表 提醒 状态` | 查看开关、北京时间及最近一次发送结果 |

课表命令只在 QQ 单聊生效。机器人本身的单聊访问权限由 QQ 控制。QQ 主动消息受客户端开关和平台频控影响。当天的发送机会由 D1 原子占用，QQ 返回失败或发送结果未知时可以继续查询课表。查看 Worker 日志可获得平台错误码。 [QQ 消息收发规则](https://bot.q.qq.com/wiki/develop/api-v2/server-inter/message/overview.html)

## 导入范围

插件支持 UTC、ICS 内定义的时区和 Asia/Shanghai，浮动时间按北京时间解释。普通课程逐条读取，周期课程支持 RRULE、EXDATE、日期时间 RDATE 和单次改期。周期展开范围是导入日前 180 天至未来 366 天。全天项目、取消的项目、ICS 内置提醒会被跳过。没有时区定义的其他时区，以及批量改期和时间段 RDATE，需要先在原日历展开为单次事件。文件上限 256 KiB，每次最多导入 1500 次课程。

## 安装

需要启用 D1 的 QFlareBot。在机器人管理面板的「插件 → 安装插件」中填入本插件的公开 GitHub 仓库地址。安装构建使用仓库根目录的 `manifest.json` 和 `package-lock.json`。

## 本地开发

把本仓库与框架仓库 `qqbot-workers` 放在同一父目录。使用 Node.js 22 或更新版本，先在框架目录运行 `pnpm install --frozen-lockfile` 和 `pnpm --filter '@qqbot/plugin-cli...' build`，再在本插件目录运行：

```sh
npm ci
npm run typecheck
npm test
npm run sync
```

`npm run sync` 会生成构建产物并更新供面板安装用的 `manifest.json`。
